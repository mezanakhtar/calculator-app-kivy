# 🧮 Calculator App using Python & Kivy

A simple and user-friendly desktop calculator application built with **Python** and the **Kivy** framework. This project demonstrates GUI development, event handling, and basic arithmetic operations using a responsive graphical user interface.

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧹 Clear Display
- 🎨 Simple and Clean User Interface
- ⚡ Responsive Button Layout

---

## 🛠️ Technologies Used

- Python 3.11
- Kivy 2.3.1

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/mezanakhtar/calculator-app-kivy.git
```

### 2. Navigate to the project directory

```bash
cd calculator-app-kivy
```

### 3. Install the required package

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python calculator.py
```
